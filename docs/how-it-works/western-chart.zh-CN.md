## 5. 输入输出与计算流程契约

### 输入参数
- `datetime`：出生地挂钟时间字符串（`YYYY-MM-DD HH:MM:SS`）。
- `utcOffset`：出生时刻当地生效的时区偏移量（含夏令时 DST），格式如 `+08:00` 或 `-05:00`。
- `latitude`：地理纬度十进制数值（$-90.0$ 至 $+90.0$）。
- `longitude`：地理经度十进制数值（$-180.0$ 至 $+180.0$）。

### 核心解算链条
所有角度均以度为单位；三角函数按弧度取值计算。
1. **世界时（UT）推导**：通过整型时间运算得出绝对时间：
   ```
   utcMs = Date.UTC(year, month − 1, day, hour, minute, second) − offsetHours × 3,600,000
   ```
2. **J2000 日数换算**：转换至标准 J2000 天文历元天数：
   ```
   j2000Days = (utcMs − 946,728,000,000) / 86,400,000
   ```
3. **当日真黄赤交角（`obliquity`）**：平黄赤交角加章动修正量：
   ```
   obliquity = meanObliquity(j2000Days) + nutationInObliquity(j2000Days)
   ```
4. **上升点/中天球面三角解析**：由格林尼治视恒星时（`gastHours`）推算中天赤经，进而闭式求解 ASC 与 MC 黄经：
   ```
   ramc         = norm360(gastHours × 15 + longitude)      // 中天赤经
   mcLongitude  = norm360(atan2(sin(ramc), cos(ramc) × cos(obliquity)))
   ascLongitude = norm360(atan2(cos(ramc), −(sin(ramc) × cos(obliquity) + tan(latitude) × sin(obliquity))))
   ```
