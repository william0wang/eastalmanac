# 五行旺衰打分模型：完整权重表与判定规则

_最后验证于：2026-10_

## 摘要导读
多数排盘与算命应用将“五行强弱”和“身强身弱”当作不可见的“黑盒算法”。EastAlmanac 采用一套完全确定、数学透明的评分模型，其理论渊源出自子平命理经典《渊海子平》的“以月令为纲”学说：将天干透出与地支藏干赋予固定的基准权重，再乘以月令季节的“旺相休囚死”五级调控系数，最终加权求和得出五行各自的总得分。当“日主自身”与“生我之印星”在全盘总分中的合计占比达到 50% 及以上时，判定为**身强**；低于 50% 则判定为**身弱**。最后依据正统**扶抑法**推导出喜神、用神与忌神。

---

## 1. 输入与输出规范

### 输入要素
一个经过有效性验证的四柱八字命盘：
- 年、月、日、时四柱天干及其所属五行。
- 四柱地支及其所属**本气/主气**、**中气**、**余气**藏干。
- 确认日主（日柱天干）与月令（月柱地支本气五行）。

### 输出要素
- 木、火、土、金、水五行的精确数值得分及其在全盘中的百分比份额。
- 日主身强弱判定：`strong`（身强）或 `weak`（身弱），附带精确的生扶党占比。
- 排序后的喜用神列表：第一顺位为**用神**，次顺位为**喜神**。
- 加剧五行失衡的**忌神**。

## 2. 完整数学模型

### A. 位置基准权重（得地与得势）
根据子平传统命理学说，透出于四柱天干的能量显露在外、作用直接；而潜藏于地支之中的藏干则为深层蓄积之气（根气）：

| 能量形态 | 位置与角色 | 基准权重 | 命理设定依据 |
|---|---|---|---|
| **透干** | 任意四柱天干 | **100** | 能量完全显现，对外直接发生作用 |
| **主气/本气** | 地支最主导的藏干 | **60** | 地支最深沉、最稳固的根本气脉 |
| **中气** | 地支次要藏干 | **30** | 关联三合局化气或季节进退之气 |
| **余气** | 地支末尾微弱藏干 | **15** | 前一节气更替所残留的边缘余蕴 |

> **日主天干注记**：日主本身显露于日干，在参与季节调控系数计算前，同样享有天干标准的 100 分基准权重。

---

### B. 季节调控倍率（得令：旺相休囚死）
月柱地支（月令）决定了整个命盘的气候背景与主宰力量（“以月令为纲”）。全盘每一个天干与藏干，都必须对照月令主气五行计算其当令状态：

| 季节状态 | 古典定义 | 调控乘数 | 能量状态释义 |
|---|---|---|---|
| **旺 (Prosperous)** | 与月令五行完全相同 | **1.5** | 得时乘旺，能量处于年度顶峰 |
| **相 (Strong)** | 受月令五行所生之五行 | **1.2** | 受到当令气候持续滋润与催生 |
| **休 (Resting)** | 生助月令五行之五行（母气） | **1.0** | 产出当令能量后，元气有所消耗而归于休歇 |
| **囚 (Imprisoned)** | 克制月令五行之五行 | **0.8** | 逆犯当令威权，受大环境抑制压伏 |
| **死 (Dead)** | 受月令五行所克之五行 | **0.6** | 受到当令气候彻底克制剥夺，处于极弱边缘 |

---

### C. 五行总分求和公式

对于五行中的每一元素（`wood` 木、`fire` 火、`earth` 土、`metal` 金、`water` 水）：

```
elementScore = Σ（该五行的透干）  stemWeight × seasonFactor(element, monthCommander)
             + Σ（该五行的藏干）  hiddenWeight(role) × seasonFactor(element, monthCommander)
```

其中：
- `monthCommander` —— 月令地支的主气五行（月令）。
- `seasonFactor(element, monthCommander)` —— 表格 B 中对应的季节状态乘数（旺相休囚死）。
- `stemWeight` = 100；`hiddenWeight(role)` 按角色取表格 A 中的 {60, 30, 15}。
- `totalChartScore` —— 五个 `elementScore` 之和，即全盘五行总得分。
- `elementShare` = `elementScore / totalChartScore`，即某五行全盘占比。

---

### D. 身强与身弱划分（扶抑临界点）
模型将五行分为两大阵营：
1. **生扶党（印比党）**：日主自身五行（比肩/劫财，同我） + 生助日主的五行（正印/偏印，生我）。
2. **克泄耗党**：克制日主的五行（正官/七杀） + 日主所生的五行（食神/伤官） + 日主所克的五行（正财/偏财）。

```
supportShare = (elementScore(dayMaster) + elementScore(sealElement)) / totalChartScore
```

- 若 `supportShare` ≥ 0.50（即达到或超过 50%），判定为**身强**。
- 若 `supportShare` < 0.50，判定为**身弱**。

### E. 喜用神与忌神推导（正统扶抑法则）

扶抑法以“损有余而补不足、中和为贵”为核心宗旨：

#### 场景 1：日主身弱
自我能量不足，急需强化与滋养：
- **用神（主要良药）**：**印星（生我者）** —— 如母亲般直接给予滋养生发之源。
- **喜神（辅助良药）**：**比劫（同我者）** —— 结伴同行，共同承担外界压力。
- **忌神（加剧失衡者）**：**官杀（克我）**、**食伤（泄我）**与**财星（耗我）**。

#### 场景 2：日主身强
自我能量过剩，必须引通疏导或予以制衡：
- **用神（主要良药）**：**官杀（克我者）** —— 给予规矩与淬炼，使过盛精力转化为事业秩序。
- **喜神（辅助良药）**：**食伤（我生者）** —— 倾吐才华，将多余力量向外创造转化；以及**财星（我克者）** —— 消耗过剩体力以达成现实目标。
- **忌神（加剧失衡者）**：**印星（生我）**与**比劫（同我）**。

## 3. 金样命例完整演算

取自测试套件严格对齐的真实标准样本：男命公历 **1990-01-15 14:30 (+08:00)**

### 四柱盘面
- **年柱**：己巳 —— 天干：己（土）；地支：巳（火；藏干：丙火主气 60、庚金中气 30、戊土余气 15）
- **月柱**：丁丑 —— 天干：丁（火）；地支：丑（土；藏干：己土主气 60、癸水中气 30、辛金余气 15）。**月令 = 丑土**。
- **日柱**：庚辰 —— 天干：庚（金，**日主**）；地支：辰（土；藏干：戊土主气 60、乙木中气 30、癸水余气 15）
- **时柱**：癸未 —— 天干：癸（水）；地支：未（土；藏干：己土主气 60、丁火中气 30、乙木余气 15）

### 季节乘数（月令主气 = 土）
- 土：旺 $\times 1.5$
- 金（土生金）：相 $\times 1.2$
- 火（火生土）：休 $\times 1.0$
- 木（木克土）：囚 $\times 0.8$
- 水（土克水）：死 $\times 0.6$

### 分项得分累计
1. **木**：
   - 辰中乙木（中气 30）：$30 \times 0.8 = 24.0$
   - 未中乙木（余气 15）：$15 \times 0.8 = 12.0$
   - **木总分 = 36.0**（占比 3.87%）

2. **火**：
   - 月干丁火：$100 \times 1.0 = 100.0$
   - 巳中丙火（主气 60）：$60 \times 1.0 = 60.0$
   - 未中丁火（中气 30）：$30 \times 1.0 = 30.0$
   - **火总分 = 190.0**（占比 20.44%）

3. **土**：
   - 年干己土：$100 \times 1.5 = 150.0$
   - 巳中戊土（余气 15）：$15 \times 1.5 = 22.5$
   - 丑中己土（主气 60）：$60 \times 1.5 = 90.0$
   - 辰中戊土（主气 60）：$60 \times 1.5 = 90.0$
   - 未中己土（主气 60）：$60 \times 1.5 = 90.0$
   - **土总分 = 442.5**（占比 47.61%）

4. **金**：
   - 日干庚金（日主）：$100 \times 1.2 = 120.0$
   - 巳中庚金（中气 30）：$30 \times 1.2 = 36.0$
   - 丑中辛金（余气 15）：$15 \times 1.2 = 18.0$
   - **金总分 = 174.0**（占比 18.72%）

5. **水**：
   - 时干癸水：$100 \times 0.6 = 60.0$
   - 丑中癸水（中气 30）与辰中癸水（余气 15）：$(30 + 15) \times 0.6 = 27.0$
   - **水总分 = 87.0**（占比 9.36%）

### 最终判决
- **全盘五行总得分**：$36.0 + 190.0 + 442.5 + 174.0 + 87.0 = \mathbf{929.5}$
- **生扶党（庚金 174.0 + 己土 442.5）**：$616.5$
- **生扶党全盘占比**：$\frac{616.5}{929.5} \approx \mathbf{66.33\%}$
- 因为 $66.33\% \ge 50\%$，该八字确定为**身强**。
- **喜用神取用**：
  - 用神：**火**（官杀，克我）
  - 喜神：**水**（食伤，我生）与 **木**（财星，我克）
- **忌神**：**土**（印星）与 **金**（比劫）

## 4. 架构边界与未覆盖的特殊格局说明

为了确保底层计算高度纯粹、可复现并且最大程度规避误判，本计算引擎专注实现覆盖全人群 85% 以上的**正统扶抑法则**，并在系统设计上对以下三类特殊格局划定了明确边界：

1. **从格（弃命顺势）**：当八字日主极度衰弱无依，命理学认为应当顺从最强五行（如从财、从杀）。然而，命理界千百年来对于“真从”还是“假从”、地支微根是否破格的界定标准存在极大分歧。硬编码的生硬规则误判率极高（一旦误判，喜忌全盘相反），因此此类极端八字交由上层大模型在具体情境中动态微调。
2. **专旺格（一气专旺）**：八字某一五行独霸（如曲直、炎上），不宜克制只能顺泄。由于其占全人群比例不足 3%，本基础算分层不强行改判。
3. **调候法则（寒暖燥湿）**：古籍《穷通宝鉴》主张冬生必用火暖局、夏生必用水解渴，先于扶抑。未来版本将计划将“调候”作为辅助提示层平滑引入，而非暴力改写基础算分。
