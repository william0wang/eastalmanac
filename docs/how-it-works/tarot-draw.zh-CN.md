# 塔罗抽牌引擎：种子化洗牌、正逆位流与永不漂移的永久链

_最后校验：2026-10_

## 摘要
EastAlmanac 的塔罗使用经典 **韦特牌（RWS 1909）**——完整 78 张——抽牌引擎与易经引擎遵守同一纯度契约：**内部无 `Math.random()`、无时钟**。页面把「揭牌时刻 + 用户挑牌背的顺序」折叠成一个 32 位**种子**；种子化 Fisher-Yates 洗牌摊开整副牌，另一条独立哈希流决定每个牌位的正逆位。同一种子 → 永远同一副牌。`/r/` 永久链携带 `{牌阵, 种子}`，边缘渲染器直接重跑引擎——**分享链永远不可能偏离用户实际抽到的结果**。

## 1. 牌库

固定牌序共 78 张：22 张大阿卡纳（`the-fool` … `the-world`，牌序 0–21），随后四个花色——权杖、圣杯、宝剑、星币——各从 Ace 到 King（22–77）。引擎的 `TAROT_DECK` slug 列表与牌面数据文件（`cards.json`）由测试断言完全一致：一个真相、两面镜子、互相校验，永不漂移。

## 2. 四种牌阵

| 牌阵 | 牌位数 | 各位含义 |
|---|---|---|
| `daily` | 1 | 当下 |
| `three` | 3 | 过去 / 现在 / 未来 |
| `relationship` | 3 | 你 / 对方 / 之间的桥 |
| `cross` | 5 | 事情本身 / 有利因素 / 不利因素 / 建议 / 走向 |

## 3. 种子：时刻 + 挑牌顺序

```text
seed = tarotSeed(momentMs, picks)
     = Wang终结器( FNV混合( … FNV混合( 0x9e3779b9, floor(momentMs) ), picks[0] … picks[n-1] ) )
```

揭牌时刻与挑牌顺序折叠为一个 uint32。**顺序敏感**——以 `[3, 17, 42]` 的顺序挑这三张牌背得种子 `1830541152`；同样三张以 `[42, 17, 3]` 挑则得 `1873606150`。用户的选择序列就是机锋——与铜钱卦里的笔画同理。

## 4. 抽牌：种子化 Fisher-Yates + 独立正逆位流

**摊牌（洗好的牌序）**：从种子的哈希值出发，`i` 从 77 递减到 1；每步刷新哈希（`Wang终结器(mix(hash, i))`）并把位置 `i` 与位置 `hash mod (i+1)` 交换。牌阵的第 *s* 位取 `fan[s]`。

**正逆位**：每个牌位的正逆位来自**另一条**流——`Wang终结器(mix(seed XOR 0x5f, slot))` 的最低位——按位独立决定，不是洗牌时预先烙进牌里。

注意：用户在屏幕上看到的摊开牌面只是呈现层——**种子完全决定抽牌结果**，摊牌序列是重算出来的，不被信任。

## 5. 金样演算

| 种子 | 牌阵 | 牌（按牌位顺序，正逆位） |
|---|---|---|
| `0` | daily | 命运之轮——**逆位** |
| `123456789` | three | 死神（逆）· 权杖王后（逆）· 命运之轮（逆） |
| `4294967295` | cross | 权杖王后（逆）· 死神（正）· 宝剑六（逆）· 女祭司（逆）· 月亮（正） |
| `777` | relationship | 权杖国王（正）· 圣杯骑士（逆）· 力量（逆） |

以上钉死在测试套件里——一旦不符即抽牌公式漂移，野外所有分享链的含义都会改变。

## 6. 永久链

每次抽牌可分享为 `/r/t.<牌阵码>.<种子>`（如 `https://eastalmanac.com/r/t.3.123456789`）。牌阵码为单字母（`1` daily、`3` three、`r` relationship、`c` cross）。打开链接即解析 `{牌阵, 种子}` 并**重跑引擎**——渲染出的页面就是抽牌本身，不是存储副本。

## 7. 统计健康度（机器校验）

两万个种子扫描：78 张牌全部出现在首槽（各约 100–600 次——无牌独大）；正逆位率保持在 47%–53% 之间。种子化洗牌的表现与公平洗牌一致。
