- `datetime`: Birthplace wall-clock ISO string (`YYYY-MM-DD HH:MM:SS`).

- `latitude`: Geographic latitude in decimal degrees ($-90.0$ to $+90.0$).
- `longitude`: Geographic longitude in decimal degrees ($-180.0$ to $+180.0$).

### Mathematical Flow
All angles are in degrees; trigonometric functions are evaluated in radians.
1. **Universal Time (UT)**: Derived via integer arithmetic:

   ```
   j2000Days = (utcMs − 946,728,000,000) / 86,400,000
   ```

3. **True Obliquity (`obliquity`)**:
   `obliquity = meanObliquity(j2000Days) + nutationInObliquity(j2000Days)` — the true tilt of the ecliptic at the birth instant.
4. **Ascendant / MC Trigonometry**:
