# 三数起卦算法规范：低位位运算状态机与朱熹动爻断法

_最后验证于：2026-10_

## 摘要导读
传统易经占筮需通过四十九根蓍草的“大衍之数五十，其用四十有九”或三枚铜钱的反复摇掷，以捕捉问卦者当下的机锋感应。EastAlmanac 在数字时代将这一古法抽象为一套完全确定的数学状态机：求问者**在画布上亲手画笔画**，引擎把笔画折叠为 **0 至 99 之间的三个整数**，并把落笔时刻混入铜钱位。引擎内部**严禁使用任何伪随机数生成器（`Math.random()`）或系统时钟种子**——数字必须 100% 来自求问者的笔画与其时刻。通过 3-bit 模运算提取六爻阴阳与动静状态，再严格按照宋代大儒朱熹与汉代焦延寿的“六爻动变规则”精准选取解卦爻辞。

## 1. 核心设计哲学：算法零随机性

现代大量占卜网站为了图省事，在后台使用 `Math.random()` 随机构造卦象。在正统易理中，这是对占筮神圣性的根本破坏：
- **同声相应，同气相求（感应）**：易经占卜不是计算机制造噪点，而是通过问卦者的潜意识机缘与外部时空建立全息共振。
- **数必须出自问卦人**：如果由服务器自行生成随机数，本质上是程序在给自己算命。
- **EastAlmanac 交互契约**：严格要求前端传入三个整型数值（`firstNumber`、`secondNumber`、`thirdNumber`），范围限定在 0–99。若调用方未传递这三个数，起卦接口直接拒绝执行。

## 2. 三个数从哪来：笔画折叠 + 时刻混合

起卦页上求问者画的是笔画；引擎经两步纯函数派生出三个数：

1. **笔画折叠**（`stroke.ts`）：采样到的笔画几何由三路独立 FNV 风格哈希累加器折叠为三个 0–99 的数。手塑其数——无时钟、无随机。
2. **时刻混合**（`coin-moment.ts`）：抬笔瞬间页面把落笔时刻（`momentMs`）作为显式参数传入，引擎只重新决定每个数的**铜钱位**——低 3 位：

```text
coinBits    = (strokeNumber XOR hashMoment(momentMs, index)) AND 0b111
blendedNumber = (strokeNumber AND ~0b111) OR coinBits
```

`hashMoment` 是确定性的 32 位 FNV-1a 混合（种子 `0x9e3779b9`）加 Wang 雪崩终结步。语义即古法：**高位保留笔画（手塑其形）；低 3 位是三枚铜钱，时刻决定每枚铜钱哪面朝上。**同样笔画 + 同一时刻 → 永远同一卦；同样笔画换个时刻 → 铜钱面不同。这复原了初版应用中每位铜钱都由时刻重播种的行为——时刻本就是机锋的一部分。

**金样**（已钉死；一段 4 点笔画折叠为 `[20, 55, 21]`）：

| 输入 | 结果 |
|---|---|
| strokeNumber `[20, 55, 21]`，`momentMs = 0` | `[22, 54, 18]` |
| 同一笔画，`momentMs = 1760000000000` | `[23, 50, 23]` |
| 同一笔画，`momentMs = 1760000001000` | `[18, 50, 21]` |

注意只有低 3 位变化（20 = `0b10100` → 22 = `0b10110`；55 = `0b110111` → 54 = `0b110110`）——笔画信息始终留在数里。

## 3. 基于 3-bit 模运算的六爻状态生成

三组数字两两派生，依次从下往上生成六爻（从初爻至上爻）：
- 第一个数（`firstNumber`）派生：**初爻**（`intToYao(firstNumber)`）与 **二爻**（`intToYao(firstNumber + 1)`）
- 第二个数（`secondNumber`）派生：**三爻**（`intToYao(secondNumber)`）与 **四爻**（`intToYao(secondNumber + 1)`）
- 第三个数（`thirdNumber`）派生：**五爻**（`intToYao(thirdNumber)`）与 **上爻**（`intToYao(thirdNumber + 1)`）

### `intToYao` 判定函数
针对每个数值（`number`），提取其二进制最低 3 位（即 `number mod 8`），并统计其中活跃的 `1` 的数量（`bitCount`，即汉明重量）：

| 1 的个数 (`bitCount`) | 内部二进制状态 | 易学传统状态 | 爻线极性 | 是否发动（动爻） |
|---|---|---|---|---|
| **`bitCount = 0`**（全 0） | `0b10` | **老阴（阴动）** | 阴爻 ($--$) | **是（发动）** |
| **`bitCount = 1`**（单 1） | `0b01` | **少阳（静阳）** | 阳爻 (—) | 否（静爻） |
| **`bitCount = 2`**（双 1） | `0b00` | **少阴（静阴）** | 阴爻 ($--$) | 否（静爻） |
| **`bitCount = 3`**（全 1） | `0b11` | **老阳（阳动）** | 阳爻 (—) | **是（发动）** |

### 与三铜钱法（摇钱法）的数学同构
这种 3-bit 映射在概率拓扑上与民间三铜钱掷钱法完全一致：
- 3 背面 $\rightarrow$ 6 点（老阴，动爻）
- 2 背面 1 字面 $\rightarrow$ 7 点（少阳，静爻）
- 1 背面 2 字面 $\rightarrow$ 8 点（少阴，静爻）
- 3 字面 $\rightarrow$ 9 点（老阳，动爻）

借助低 3 位的奇偶与位权组合，算法完美复刻了四象演变的离散动力学。

## 4. 本卦、动爻与变卦推导

1. **本卦（Original Hexagram）**：
   提取六个爻位的底层极性（bit 0），由初爻（最底层）至上爻（最顶层）叠起，确定 64 卦中的原始卦象。
2. **动爻（Changing Lines）**：
   凡状态值带有变更位（bit 1 为 1，即老阴 `0b10` 或老阳 `0b11`）的爻位，均为发动之爻，代表事物发展中的关键变化因子。
3. **之卦/变卦（Transformed Hexagram）**：
   将本卦中所有动爻的极性取反（老阴变少阳、老阳变少阴），静爻保持不变，重构为代表未来归宿的新卦。

## 5. 朱熹与焦延寿六爻断卦裁决规则

当一个卦同时出现多个动爻时，究竟该读哪一句爻辞？EastAlmanac 完整内嵌了宋代理学家朱熹与西汉焦延寿整理的经典法则：

| 动爻数量 | 裁决选用的经典文本 | 易理解析逻辑 |
|---|---|---|
| **0 个动爻** | **本卦卦辞（彖辞）** | 盘面宁静无杂波，观全局之气象。 |
| **1 个动爻** | **该动爻的爻辞** | 变化聚焦于单一关口，专看此爻动向。 |
| **2 个动爻** | **优先取阴爻爻辞；同极性取上位爻** | 若一阴一阳，阴主内敛潜伏，优先看阴动；若二爻极性相同，则看上层动爻。 |
| **3 个动爻** | **取中间那个动爻的爻辞** | 三爻齐发成鼎足之势，中间动爻为气机转折枢纽。 |
| **4 个动爻** | **取之卦中较低位置的静爻爻辞（下静爻）** | 动极思静，局势动荡过甚时，未动之爻才是定海神针；取位置靠下的静爻为断。 |
| **5 个动爻** | **取之卦中唯一的静爻爻辞** | 举盘皆动，唯此一爻独善其身，以此静爻裁夺变卦。 |
| **6 个动爻** | **乾坤看用九用六；其余 62 卦看变卦彖辞** | 乾卦全变看“用九（见群龙无首，吉）”；坤卦全变看“用六（利永贞）”；其余卦象直接读取之卦的整体卦辞。 |

## 6. 金样测试算例

### 算例 1：输入 `[7, 23, 41]`
- 第一个数（`firstNumber = 7`）：
  - 7 = `0b111` → `bitCount = 3` → **初爻：老阳**（`0b11`，阳动）
  - 8 = `0b000`（8 mod 8 = 0）→ `bitCount = 0` → **二爻：老阴**（`0b10`，阴动）
- 第二个数（`secondNumber = 23`）：
  - 23 = `0b111`（23 mod 8 = 7）→ `bitCount = 3` → **三爻：老阳**（`0b11`，阳动）
  - 24 = `0b000`（24 mod 8 = 0）→ `bitCount = 0` → **四爻：老阴**（`0b10`，阴动）
- 第三个数（`thirdNumber = 41`）：
  - 41 = `0b001`（41 mod 8 = 1）→ `bitCount = 1` → **五爻：少阳**（`0b01`，静阳）
  - 42 = `0b010`（42 mod 8 = 2）→ `bitCount = 1` → **上爻：少阳**（`0b01`，静阳）

**运算结果**：
- **六爻极性（自下而上）**：阳、阴、阳、阴、阳、阳
- **本卦**：第 37 卦 —— **风火家人（家人卦）**
- **动爻集合**：共 4 个动爻（初九、六二、九三、六四发动）
- **解卦裁决**：触发 4 动爻规则，取之卦（天水讼）中位置靠下的静爻（九五爻）爻辞为断。

### 算例 2：输入 `[0, 1, 6]`
- 0 = `0b000` → `bitCount = 0` → 初爻：老阴（`0b10`，阴动）
- 1 = `0b001` → `bitCount = 1` → 二爻：少阳（`0b01`，静阳）
- 1 = `0b001` → `bitCount = 1` → 三爻：少阳（`0b01`，静阳）
- 2 = `0b010` → `bitCount = 1` → 四爻：少阳（`0b01`，静阳）
- 6 = `0b110` → `bitCount = 2` → 五爻：少阴（`0b00`，静阴）
- 7 = `0b111` → `bitCount = 3` → 上爻：老阳（`0b11`，阳动）

**运算结果**：
- **本卦**：第 50 卦 —— **火风鼎（鼎卦）**
- **动爻集合**：共 2 个动爻（初六与上九）。
- **解卦裁决**：两动爻一阴一阳，优先选用阴动爻，故以 **初六爻辞（鼎颠趾，利出否）** 为断。
