# 溯源起名引擎：只检索、不生成——永不合并的两层评分

_最后校验：2026-10_

## 摘要
起名引擎（出典起名）从不发明名字。所有候选都来自**经典语料库**——从蒙学读本、诗文经典等挖掘出的名字，每个都带精确的出处（著作、篇目、诗句、行号）。评分是**永不合并成单一数字的两层**：八字喜用匹配是*主层*、也是**唯一的排序键**；五格剖象 + 三才解读作为*次层参考*随附，自带熊崎氏出处披露。56 条谐音粗筛标记尴尬的姓+名连读——只标记、绝不剔除：决策权始终在人。

---

## 1. 语料库——检索而非生成

候选仅来自语料库条目（引擎绝不把汉字拼成新名字）。每条目携带：名字各字的五行标注、康熙笔画、《通用规范汉字表》通行度层级（1/2/3 级或表外——生僻是卖点，绝不是淘汰理由）、拼音，以及完整的**出典记录**——著作、篇目、题名、行号、字距与所出诗句。出典反查能重新定位出处字距与查询位置相隔 2 字以内的条目——每个名字都能追溯回它的诗行。本篇通篇的笔画是字库康熙笔画——画卦的笔画折叠属于易经起卦管线，规范见第一篇。

## 2. 第一层（主层）：八字喜用匹配——唯一排序键

名字每个字的五行对照命盘喜用列表（旺衰引擎给出，用神优先）定级：

| 字角色 | 分值 |
|---|---|
| 用神（药神，favorable[0]） | 3 |
| 喜神（其余喜用） | 2 |
| 中性 | 1 |
| 忌神 | 0 |

```text
baziMatchScore = (Σ 每字分值) / (3 × 字数)    → 0..1
```

排序只用这个分数、**别无其他**。字字都补命盘所需的名字得 1.0；忌神扎堆的名字趋近 0、沉底。

## 3. 第二层（次层）：五格 + 三才——仅供参考

古典五格剖象法由康熙笔画算出五个笔画和（各 +1 项是该法对缺位的虚数一）：

| 格 | 单字姓 | 复姓 |
|---|---|---|
| 天格 | 姓 + 1 | 姓₁ + 姓₂ |
| 人格 | 姓 + 名₁ | 姓₂ + 名₁ |
| 地格 | 名₁ + 1（单字名）· 名₁ + 名₂ | 同左 |
| 外格 | 2（单名）· 名₂ + 1（双名） | 姓₁ + 1（单名）· 姓₁ + 名₂（双名） |
| 总格 | 全部笔画之和 | 同左 |

**金样（与公开参考钉死比对）**：笔画 `([7], [11,12])` → 五格 8 / 18 / 23 / 13 / 30；`([15,17], [10])` → 32 / 27 / 11 / 16 / 42；`([4], [10])` → 5 / 14 / 11 / 2 / 14。

每格按**尾数**定五行（1,2 木 · 3,4 火 · 5,6 土 · 7,8 金 · 9,0 水），再查 **81 数理表**（大于 81 减 80：85 → 5）。三才（天人地）三元组索引 125 条的组合表（5 行 × 25 列）得出档位与两两关系——金样：天人地 = 木木木 → 大吉、两关系皆同；木木火 → 大吉、人生地；木金水 → 大凶。两张表的档位分布是机器校验的不变量：81 数理——大吉 22 / 大凶 22 / 吉 16 / 半吉 12 / 凶 9；三才 125——大吉 39 / 大凶 33 / 凶 24 / 吉 19 / 半吉 10。

**出处，钉死且披露**：81 表与 125 表转录自钉死的单一发布包 shunshi-naming-core@0.1.0（github.com/shunshi-ai/naming-mcp，MIT © 2026 Shunshi.AI），该包复刻熊崎健翁体系（殁于 1961——2011 年起进入公有领域）。只取档位与古典数理名（白话释义全部自写）；各家争议的数字（42、49）归档半吉，不强行定级。工具页页脚固定披露：熊崎氏体系（1918）仅供参考。

## 4. 谐音粗筛——只标记，不过滤

56 条精选规则筛查姓+名连读的尴尬谐音——精选家族：否定头（吴→无×、梅→没×、夏→下×、范→犯×/饭×）、身体与动物读音（朱→猪×、庞→膀胱、杨→阳痿），以及经典梗名（史珍香、杜子腾、朱逸群）。忽略声调（连读调侃不听调）；拼音未解析的条目无从筛起。**粗筛绝不剔除或降权任何候选**——只返回标记；决定权留给父母。

## 5. 为什么两层永不混合

把命盘需求分与笔画数理分搅成一个数字，会让好看的五格冲掉不利的五行——反之亦然。引擎的契约是：喜用定顺序；五格/三才作为标注清晰的古典参考随附、自带披露。两个数字永不相触。
